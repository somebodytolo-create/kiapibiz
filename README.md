# kiapibiz — 사업운영팀 비용 관리

KIAPI 전략기획본부 사업운영팀이 24개 R&D 과제의 **비용 항목**을 과제별·월별로 확인하는 내부용 페이지.

- 공개 주소: https://somebodytolo-create.github.io/kiapibiz/
- 현재 항목: **회의비** (과제×월 요약 + 과제 클릭 시 건별 내역)
- 예정 항목: 사무용품비 (별도 관리 양식 반영 후 추가)

## 데이터

`index.html` 하나로 끝나는 정적 페이지. 데이터는 파일 안 `const DATA = {...}` 에 인라인됩니다.

원본은 SharePoint 동기화 폴더 `본부_업무방 - 2026` 의 과제별 엑셀
`NN.(연구비사용현황)<과제>_<단계차수>_2026.xlsx` → 시트 `연구활동비(현황)` 의 회의비 세목입니다.

생성 스크립트는 원본 폴더에 있습니다.

| 스크립트 | 역할 |
|---|---|
| `대시보드_생성.py` | 엑셀 파서 (연구비 대시보드와 **공용**) |
| `사업운영_웹생성.py` | 이 페이지 생성 → `kiapibiz_work/index.html` |
| `대시보드_일일반영.py` | 매일 1회 두 사이트 재생성·커밋·푸시 (작업 스케줄러) |

수동 재생성:

```
py "사업운영_웹생성.py"
```

## 숫자 검증

회의비 예산·월별 집행액은 [연구비 집행 현황 대시보드](https://somebodytolo-create.github.io/kiapirnd/)와
**같은 파서**에서 나옵니다. 생성 시 건별 내역의 월별 합계를 대시보드 집계와 대조하고,
다르면 콘솔에 `[경고]` 를 출력합니다.

## 집계 규칙

- 지출월은 **지출내역 제목 앞의 `연.월.일`**(예: `26.04.10 회의비`)을 우선 사용합니다.
  카드 결제 건은 대금이 익월에 이체되므로 등록일자 기준으로는 실제 지출월과 어긋납니다.
- 제목에 날짜가 없으면 등록일자를 씁니다. 둘 다 없으면 `미상` 열에 잡힙니다.
- 지출결의가 등록된 건만 집계됩니다.
